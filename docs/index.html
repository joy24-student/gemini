Overview
Reverse-engineered Gemini Web UI RPC protocol wrapped in an OpenAI-compatible REST API. Drop-in replacement for any OpenAI-powered application.
ℹ️ This library operates via browser session cookies, not paid API keys. Authentication requires a Google account logged into gemini.google.com.

Authentication
Extract two session cookies from your logged-in browser session at gemini.google.com.
  1. Open gemini.google.com
    Log into your Google account, then open the page.
  2. Open DevTools → Application → Cookies
    Press F12 → Application tab → Cookies → https://gemini.google.com
  3. Copy the two required cookies
    Find __Secure-1PSID and __Secure-1PSIDTS — copy both values.
  4. Create cookies.json
    [
  {"name": "__Secure-1PSID",   "value": "YOUR_1PSID_VALUE"},
  {"name": "__Secure-1PSIDTS", "value": "YOUR_1PSIDTS_VALUE"}
]
  5. Use Auto-Extraction (easier)
    from gemini_client import Chatbot
# Automatically reads cookies from Chrome/Edge/Firefox
bot = Chatbot(auto_cookie=True)

API Reference
All endpoints are OpenAI-compatible. Swap api.openai.com for your server URL.
POST /v1/chat/completions Send a chat message. Supports streaming SSE. ▾
Request Body
FieldTypeRequiredDescription
modelstringoptionalModel ID. Default: gemini-2.5-flash
messagesarrayrequiredArray of {role, content} message objects
streambooleanoptionalEnable SSE streaming. Default: false
temperaturefloatoptionalSampling temperature 0–1. Default: 0.7
 
import openai

client = openai.OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="your-api-key",  # or "none" if no auth configured
)

response = client.chat.completions.create(
    model="gemini-2.5-flash",
    messages=[{"role": "user", "content": "Hello! What can you do?"}],
)
print(response.choices[0].message.content)

🐳 Docker VPS Deployment
Full production stack: API server + nginx reverse proxy + TLS + Prometheus.
✅ Recommended for production. Supports streaming, WebSockets, voice pipeline, and 500+ concurrent users. Minimum: 1GB RAM, Ubuntu 22.04.
  1. Provision VPS & Install Docker
    sudo apt update && sudo apt upgrade -y

# Install Docker Engine
curl -fsSL https://get.docker.com | bash
sudo usermod -aG docker $USER
newgrp docker

# Install Docker Compose plugin
sudo apt install -y docker-compose-plugin
docker compose version
  2. Clone Repository
    git clone https://github.com/OEvortex/Gemini-Chat-API.git
cd Gemini-Chat-API
  3. Configure Environment Variables
    cp .env.example .env
nano .env
# Set GEMINI_1PSID and GEMINI_1PSIDTS from gemini.google.com cookies
  4. Add SSL Certificates (Let's Encrypt)
    sudo apt install -y certbot
sudo certbot certonly --standalone -d your-domain.com

# Copy certs to nginx ssl dir
sudo mkdir -p nginx/ssl
sudo cp /etc/letsencrypt/live/your-domain.com/fullchain.pem nginx/ssl/
sudo cp /etc/letsencrypt/live/your-domain.com/privkey.pem  nginx/ssl/

# Update nginx/default.conf: set server_name your-domain.com
  5. Build & Launch
    # Build image and start all services
docker compose up -d --build

# Watch logs
docker compose logs -f api

# Verify all services are healthy
docker compose ps
  6. Verify Deployment
    curl https://your-domain.com/health/live
# → {"status":"live"}

curl https://your-domain.com/v1/models
# → {"object":"list","data":[...]}

# Test chat
curl -X POST https://your-domain.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hello!"}]}'
  7. Enable Monitoring (optional)
    # Start with Prometheus metrics collection
docker compose --profile monitoring up -d

# Access Prometheus at http://localhost:9090 (tunnel if on remote VPS)
ssh -L 9090:localhost:9090 user@your-vps-ip

▲ Vercel Deployment
Deploy the REST API as serverless functions with zero infrastructure management. Best for simple chat completions without streaming or WebSocket features.
⚠️ Vercel Hobby plan has a 60s function timeout and no WebSocket support. For streaming, live voice, and 500+ user concurrency, use the Docker VPS setup instead.
  1. Install Vercel CLI & Login
    npm install -g vercel
vercel login
  2. Clone the Repository
    git clone https://github.com/OEvortex/Gemini-Chat-API.git
cd Gemini-Chat-API
  3. Set Secret Environment Variables
    # Add your Google session cookies as Vercel secrets
vercel env add GEMINI_1PSID
# Paste your __Secure-1PSID value when prompted

vercel env add GEMINI_1PSIDTS
# Paste your __Secure-1PSIDTS value when prompted
  4. Deploy to Production
    vercel --prod
# → Deployed to: https://your-project.vercel.app
  5. Test Your Deployment
    curl https://your-project.vercel.app/health
# → {"status":"ready","cookies":"configured"}

curl -X POST https://your-project.vercel.app/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hello from Vercel!"}]}'
  6. Connect to OpenAI SDK
    import openai

client = openai.OpenAI(
    base_url="https://your-project.vercel.app/v1",
    api_key="none",  # No auth key required by default
)

response = client.chat.completions.create(
    model="gemini-2.5-flash",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.choices[0].message.content)

Python SDK
Use the library directly without the REST server for embedded applications.
from gemini_client import Chatbot, Model

bot = Chatbot(cookie_path="cookies.json", model=Model.G_2_5_FLASH)
response = bot.ask("What is the capital of France?")
print(response.text)          # → "The capital of France is Paris."
print(response.conversation_id)
import asyncio
from gemini_client import AsyncChatbot, Model

async def main():
    bot = await AsyncChatbot.create(
        secure_1psid="YOUR_1PSID",
        secure_1psidts="YOUR_1PSIDTS",
        model=Model.G_2_5_FLASH,
    )
    response = await bot.ask("Hello, Gemini!")
    print(response.text)
    await bot.session.aclose()

asyncio.run(main())
import asyncio
from gemini_client import AsyncChatbot

async def main():
    bot = await AsyncChatbot.create(secure_1psid="...", secure_1psidts="...")
    async for chunk in bot.ask_stream("Write a short story."):
        print(chunk, end="", flush=True)
    print()

asyncio.run(main())
from gemini_client import Chatbot
from gemini_client.memory import ConversationMemory

memory = ConversationMemory(
    session_name="my_session",      # auto-saves to ~/.gemini/memory/
    system_instruction="You are a concise assistant.",
)

bot = Chatbot(cookie_path="cookies.json", memory=memory)
r1 = bot.ask("My name is Alice.")
r2 = bot.ask("What is my name?")   # → "Your name is Alice."
print(r2.text)
JavaScript / Node.js
// With openai npm package (drop-in)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://localhost:8000/v1",
  apiKey:  "your-api-key",
});

// Standard request
const response = await client.chat.completions.create({
  model: "gemini-2.5-flash",
  messages: [{ role: "user", content: "Hello!" }],
});
console.log(response.choices[0].message.content);

// Streaming
const stream = await client.chat.completions.create({
  model: "gemini-2.5-flash",
  messages: [{ role: "user", content: "Write a poem." }],
  stream: true,
});
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
