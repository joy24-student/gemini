🐳 Docker VPS Deployment

      
Run using Docker Compose with Nginx reverse proxy and TLS:

      
git clone https://github.com/joy24-student/gemini.git
cd gemini
docker compose -f docker/docker-compose.yml up -d --build

    


    

      
▲ Vercel Serverless Deployment

      
Deploy directly to Vercel Serverless Functions:

      
npm install -g vercel
vercel env add GEMINI_1PSID
vercel env add GEMINI_1PSIDTS
vercel --prod
